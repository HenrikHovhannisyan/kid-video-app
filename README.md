# Kid Video App

Kid Video App is a child-friendly video platform designed to provide a safe and engaging environment for children to watch curated video content. The application includes parental controls and a math captcha system to ensure children's safety while using the platform.

## Features

- **Curated Video Content**: Safe and educational videos suitable for children
- **Parental Controls**: Math captcha system to restrict certain actions
- **Favorites**: Ability to save favorite videos for quick access
- **Responsive Design**: Works seamlessly on both desktop and mobile devices
- **User Authentication**: Secure login system for parents and guardians

## Technologies Used

- React.js
- Firebase (Authentication & Database)
- CSS Modules
- YouTube API Integration

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager
- Firebase account

### Installation

1. Clone the repository:

```bash
git clone https://github.com/HenrikHovhannisyan/kid-video-app.git
```

2. Install dependencies:

```bash
npm install
```

3. Create a Firebase project and update the configuration in `src/firebase.js`

4. Start the development server:

```bash
npm start
```

The application will be available at `http://localhost:3000`

### Building for Production

To create a production build:

```bash
npm run build
```

## Usage

1. Register a parent account to access the full functionality
2. Browse through the curated video collection
3. Add videos to favorites for quick access
4. Use parental controls when needed
